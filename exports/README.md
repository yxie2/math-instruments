# Catalogue exports

- [Complete catalogue as JSON](catalog.json): metadata and Markdown bodies for instruments, papers, families and patterns.
- [Instruments as CSV](instruments.csv)
- [Source papers as CSV](papers.csv)
- [Families as CSV](families.csv)

These files are generated by `python scripts/build_indexes.py`. Edit the Markdown records under `catalog/`, then regenerate. In CSV exports, list fields use semicolons; use JSON when full structure is needed.

Stable record identifiers are the keys for joining exports. Retain the repository release or commit when citing a dataset snapshot.
