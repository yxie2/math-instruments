Copy a template to its destination and replace the example values before submitting it. Allocate an unused identifier and retain it through later revisions. Use YAML strings for identifiers and dates; leading zeros in source-family numbers are significant.

Keep ordinary Markdown and LaTeX mathematics in the body. GitHub supports inline mathematics with dollar delimiters and displayed equations in a `math` code block.

The files in this directory are examples, not catalogue entries.
