- Family 283: programmable slots contain arbitrary controlled tables. The dilation tests check the singular-vector calculation, not the complete circuit compilation or oracle construction.
- Family 284: the direct product is an established tool with individual query caps. The comparison search returns a list and its guarantee does not require transitivity. The global total-function separation is outside this review.
