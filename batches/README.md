# Extraction batches

| Batch | Coverage | Description |
|---|---|---|
| [B001](B001/README.md) | 38 families; 115 instrument entries; 81 source-manuscript records | Initial direction-paper extraction, including the original groups of 17 and 21 |

Future rounds use `B002`, `B003`, and subsequent unused identifiers. Each batch records the source versions and the records it adds or revisits. A batch is an extraction event, not a new copy of the whole catalogue.

Use the [batch template](../templates/batch.yaml) and the [contribution guide](../CONTRIBUTING.md). Existing instrument and family identifiers remain stable across batches.
