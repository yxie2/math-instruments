# Extraction batches

| Batch | Coverage | Description |
|---|---|---|
| [B001](B001/README.md) | 38 families; 115 instrument entries; 81 source-manuscript records | Initial direction-paper extraction, including the original groups of 17 and 21 |
| [B002](B002/README.md) | 4 new families; 9 instruments; 4 source manuscripts | Quantum information, entropy and threshold mechanisms, with exact source locators and selected finite checks |
| [B003](B003/README.md) | 4 new families; 10 instruments; 4 source manuscripts | Moment-coordinate estimates, relative-moment embeddings, metric obstructions and Jacobian rigidity |

Future rounds use `B004` and subsequent unused identifiers. Each batch records the source versions and the records it adds or revisits. A batch is an extraction event, not a new copy of the whole catalogue. The [release coverage table](../tables/coverage.md) lists catalogued and pending families.

Use the [batch template](../templates/batch.yaml) and the [contribution guide](../CONTRIBUTING.md). Existing instrument and family identifiers remain stable across batches.
