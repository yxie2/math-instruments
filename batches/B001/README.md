# B001 — Initial direction-paper extraction

This batch imports 38 family entries, all 115 instrument descriptions, and eleven recurring patterns from Ying Xie's direction manuscript. The original first group contains 17 families and the second contains 21; both were part of the initial extraction.

There are also 81 source-manuscript records for the selected families, including companion papers. These are source associations, not 81 separate completed extractions.

The import preserves the mathematical descriptions and existing qualifications. It performs format and catalogue checks; it adds no independent certification of source proofs or novelty. Exact attribution within multi-manuscript families remains as specified in each description rather than being inferred from family membership.
