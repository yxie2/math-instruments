# Remove alphabet size by collision-controlled hashing and a direct sum

[Family 099](../families/openai-math-099.md) · [Source manuscript](../papers/P-000455.md) · [Batch B073](../../batches/B073/README.md)

## Mathematical content

Let ID denote insertion-deletion distance on strings of length at most d. Relabel each alphabet symbol independently and uniformly in [q], q=4d^2. Relabeling cannot increase ID. For any fixed pair x,y, at most 2d symbols occur, and the probability of a collision on those symbols is at most choose(2d,2)/q<1/2. On the complementary event every equality pattern is preserved, so the longest common subsequence and ID are unchanged.

Suppose a map g on the bounded alphabet satisfies a ID(u,v)<=||g(u)-g(v)||_1<=b ID(u,v). The finite direct sum over all hashes h, with coordinates Pr(h)[g(h(x))-g(h(empty))], has distance equal to the expected component distance. It is between a ID(x,y)/2 and b ID(x,y). The map is global even though the injective event is chosen separately for each pair.

The source supplies binary delimiter coding and a binary embedding as inputs, yielding component estimates ED(x,y)/4 and 4w D_m ED(x,y) on the appropriate sides, where w=2 ceil(log2 q)+3 and m=wd. Averaging yields ED/8 and 4wD_m ED, hence distortion 32wD_m independent of alphabet size. The extraction verifies the hashing and averaging step; the code estimates remain dependencies.

## Role in the source argument

Transfers a bounded-alphabet embedding to arbitrary finite alphabets with a constant loss at the averaging stage.

## Antecedents and comparison

[Ostrovsky and Rabani, preliminary manuscript dated August 19, 2005](https://web.cs.ucla.edu/~rafail/PUBLIC/68.pdf), Theorem 7 on printed page 7, supplies the established binary upper-bound scale; that statement was read. The pairwise hashing/direct-sum reduction is the selected interface, not a new binary embedding theorem.

## Checks and limitations

Exact enumeration of small hash families checks nonexpansion, injective-event preservation and the union bound, including empty strings. A finite l1 map checks that direct-sum distance equals its expectation.

No full edit-distance embedding, delimiter code or lower-bound witness is certified.

## Possible applications

Uniformizing alphabet-dependent constructions when each tested pair uses few symbols.

These are proposed uses; no subsequent application is recorded for this instrument.
