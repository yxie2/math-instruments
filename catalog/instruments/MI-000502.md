# Replay a linear DAG twice to restore arbitrary borrowed memory

[Family 130](../families/openai-math-130.md) · [Source manuscript](../papers/P-000281.md) · [Batch B050](../../batches/B050/README.md)

## Mathematical content

Suppose M:C^e->C^a is computed by a linear DAG with g gates, depth H, fan-in at most two, and fan-out at most delta counting output uses. Each output reads one source, one gate or zero. On disjoint registers x,y,z of sizes e,a,g, implement (x,y,z)->(x,y+Mx,z) even when z initially contains arbitrary values correlated with x or y.

Associate one z register with each gate and add its prescribed predecessor combination in topological order. The resulting sweep is z->Uz+Tx, with U unit lower triangular. If the readout is Fz+Dx, then FT+D=M. Compute, add the readout to y, and reverse the sweep: z is restored, but y has gained Mx+FUz. Repeat the sweep omitting direct-source edges, subtract the readout FUz, and reverse again. The net effect is exactly the desired shear, with all borrowed registers restored.

Four sweeps use at most 8g elementary shears and two readouts use at most 2a. Within each depth level, the shear-edge multigraph has degree at most max{2,delta}; greedy edge coloring partitions it into at most twice that degree minus one disjoint-pair layers. Destinations are not predecessors at the same level, so this reordering is valid. Overall layer count is O((delta+1)(H+1)). Outputs are never used as predecessors in either sweep.

## Role in the source argument

Lets the uniform Fourier source use existing coordinates as convolution workspace without assuming they are zero.

## Antecedents and comparison

[Buhrman et al., Computing with a Full Memory: Catalytic Space](https://ir.cwi.nl/pub/22659/22659B.pdf), Section 3, defines transparent computation and a compute/read/reverse cleanup restoring arbitrary initial register contents. These passages were read. The source supplies the displayed source-suppressed linear replay and the pair-layer accounting.

## Checks and limitations

Exact rational DAGs are evaluated on symbolic independent input, target and workspace registers. The composed map is compared with direct DAG evaluation, and one-pass controls exhibit the uncancelled initial-memory term.

This does not certify that all source convolution instances fit the available coordinate budget, or establish its Fourier running-time bound.

## Possible applications

Linear updates using borrowed registers that carry unrelated data and must be restored exactly.

These are proposed uses; no subsequent application is recorded for this instrument.
