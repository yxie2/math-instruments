# Freeze inactive branches to preserve complete polynomial-witness uniqueness

[Family 242](../families/openai-math-242.md) · [Source manuscript](../papers/P-000156.md) · [Batch B021](../../batches/B021/README.md)

## Mathematical content

A single-fold system for R(a) has exactly one complete auxiliary tuple when R(a) is true and none otherwise. Conjunction preserves this property when calls use separate auxiliary tuples and their displayed arguments are fixed. Composition of single-fold function graphs determines every intermediate output and its auxiliaries successively.

For pairwise disjoint cases i=1,...,r, introduce natural selectors e_i satisfying e_i(e_i-1)=0 and sum e_i=1. Multiply every equation F=0 of case i, including its guard and all nested-call equations, by e_i. For every variable z local to that case impose (1-e_i)z=0. This freezes inactive outputs, slacks, normalization variables and nested selectors. Shared displayed arguments are not frozen. Disjointness makes the active selector unique, its system fixes its witness, and every inactive tuple is zero.

Function cases require guards partitioning the input domain and an active case determining the shared output. For max(a,b), use a>=b and a<b to assign ties once. Inequalities use unique nonnegative slacks; integer signs use z=z_plus-z_minus with z_plus z_minus=0. Finally replace equations F_i=0 by sum F_i^2=0 without changing variables or solutions.

Gating the equations alone is insufficient: an inactive branch then leaves its local variables free, destroying uniqueness even if the output is unique.

## Role in the source argument

Provides a ledger-preserving assembly rule for all later arithmetic and computation encodings.

## Antecedents and comparison

[Cantone-Cuzziol-Omodeo, Section 2, pp. 590-591](https://lematematiche.dmi.unict.it/index.php/lematematiche/article/download/2703/1218/7841) explicitly explains why naive disjunction loses uniqueness and fixes unused witnesses. The source applies this established requirement recursively to all local variables.

## Checks and limitations

Read the proof and the antecedent discussion. Exact enumeration of guarded maximum systems checks the unique full tuple on 36 inputs, including ties, and demonstrates extra witnesses when inactive variables are not frozen.

This is a closure rule for systems already known to be single-fold. It does not create single-fold exponentiation or a representation of every recursively enumerable set.

## Possible applications

Building arithmetic encodings whose outputs and every hidden auxiliary remain uniquely determined.
