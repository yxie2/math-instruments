# Finite response bounds extend by limsup to a canonical infinite-volume drift

[Family 231](../families/openai-math-231.md) · [Source manuscript](../papers/P-000093.md) · [Batch B005](../../batches/B005/README.md)

## Mathematical content

For a finite weighted spanning-tree law with log weights h and inclusion means p, differentiation gives $\partial_{h_f}p_e=\operatorname{Cov}(X_e,X_f)$. Negative off-diagonal covariances and the fixed tree size yield

$$\sum_f|\partial_{h_f}p_e|=2p_e(1-p_e)\le\tfrac12.$$

For a general finite strongly Rayleigh binary law the equality becomes an inequality. Exponential tilting preserves that property, so the same uniform response bound holds at every finite field. This covariance estimate is an established input.

For the free uniform spanning forest law nu and finite edge set S, define

$$b_{e,S}(t,y)=\frac{\mathbb E_\nu[X_e\exp\{\sum_{f\in S}(y_f-t/2)X_f\}]}{\mathbb E_\nu[\exp\{\sum_{f\in S}(y_f-t/2)X_f\}]}.$$

The denominator is positive. A free finite-graph limit, taken with S fixed, preserves the response bound. Let $S_n(e)$ be the edges induced by the vertices within distance n of either endpoint of e, and set $b_e(t,y)=\limsup_n b_{e,S_n(e)}(t,y)$. This produces a jointly Borel, root-free, isomorphism-equivariant drift on all real edge fields, with values in $[0,1]$, and

$$\sup_e|b_e(t,y)-b_e(t,y')|\le\tfrac12\sup_f|y_f-y'_f|$$

whenever the right side is finite. Neither field is required to be bounded. Taking the two limsup inequalities in opposite directions proves the estimate. The outer limsup need not be a limit on arbitrary inputs; along the observation process it agrees almost surely at each fixed time with the posterior mean.

## Role in the source argument

Makes a posterior drift available on every path input without defining an infinite-volume partition function or imposing a bounded-field state space.

## Antecedents and comparison

The row bound is already stated in [Alishahi, Barzegar and Zamani, Lemma 2.5 and equation (1)](https://arxiv.org/html/2203.03935v2), following earlier work of [Ghosh, Liggett and Pemantle](https://arxiv.org/abs/1607.03036v1). The extracted construction combines that input with fixed-field forest limits and an intrinsic outer limsup; the classical bound is not a new result.

## Checks and limitations

Read the finite matrix-tree response proof, the strongly Rayleigh homogenization argument, and the two ordered spatial limits. Exact rational enumeration checks weighted tree covariances, including bridges; finite determinant examples check the nonhomogeneous covariance inequality.

The order of limits matters: first the finite-graph limit with S fixed, then the limsup over S. Negative pairwise correlations alone do not supply the row bound. Equivariant exhaustions or another equivariant drift construction are needed for a factor conclusion.

## Possible applications

Constructing globally defined posterior drifts for other negatively dependent infinite-volume laws, with the finite response estimate as a reusable criterion.

These are proposed uses; no subsequent application is recorded for this instrument.
