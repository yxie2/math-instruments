# Pass to a minimal idempotent corner without losing unit lifts

[Family 129](../families/openai-math-129.md) · [Source manuscript](../papers/P-000279.md) · [Batch B050](../../batches/B050/README.md)

## Mathematical content

Let theta:A->M be a surjective multiplicative map from a finite semigroup to a monoid, and let q in M be idempotent. An idempotent preimage exists because every element of a finite semigroup has an idempotent positive power. Choose a minimal such d under e<=d meaning ed=de=e. Restriction gives a unital surjection dAd->qMq.

Every w in dAd whose image is a unit is itself a unit. An idempotent power w^k has image a unit idempotent, hence q; it lies below d, so minimality forces w^k=d. Then w^(k-1) is an inverse, with k=1 giving w=d. Thus units lift within this selected corner. An arbitrary idempotent preimage does not have this property.

For the full relation monoid R_H, let P^2=P and i=I_F for F subset H, with iPi=i. Set Q=PiP. Then Q^2=Q, PQ=QP=Q, and restriction Z->iZi is a unital isomorphism Q R_H Q -> R_F, inverse A->PAP. For Z=QZQ, the identity Z=PiZiP proves injectivity; for A supported on F, i(PAP)i=A. Moreover (PAP)(PBP)=PABP, using P^2=P and iPi=i. This isolates the smaller relation monoid while preserving multiplication and the local identity.

## Role in the source argument

Allows the nondeterministic source amplification to restrict to smaller relation images and still lift their permutations.

## Antecedents and comparison

The proof uses elementary idempotent-power and corner arguments from finite-semigroup theory. The complete selected source proofs were read. A targeted search did not determine the earliest reference for this exact combined formulation; it is not labeled a new semigroup theorem.

## Checks and limitations

Finite transformation-semigroup products test minimal idempotents and all their unit preimages. Exact enumeration of small binary relations checks corner restriction, multiplication and both inverse identities. A nonminimal corner is a control.

The check does not establish the source path-diagram transport, nested-chain bound or exponential state loss.
