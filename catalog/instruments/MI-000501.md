# Turn deterministic sink reachability into one tree contour tour

[Family 129](../families/openai-math-129.md) · [Source manuscript](../papers/P-000280.md) · [Batch B050](../../batches/B050/README.md)

## Mathematical content

Let sigma be a partial function on a finite set and let t have no successor. Make an undirected multigraph with one edge for each defined successor, retaining loops and parallel edges. A vertex is in the component of t exactly when its successor orbit reaches t. Indeed, membership in the basin of t is constant across every successor edge. Every vertex of that component except t has exactly one successor, so a component of v vertices has v-1 edges and is a tree.

Give the edge incidences at each tree vertex any cyclic order. After arriving along an incidence, leave along the next one. This is a permutation on directed edge traversals, and for a nontrivial tree it is one cycle. Removing a leaf gives induction: restoring it replaces one transition (u,v)->(v,w) by (u,v)->(v,z)->(z,v)->(v,w), inserting two traversals in the same cycle. Opening the joins at two distinct leaves cuts this cycle into two paths, each joining the two leaves.

For a deterministic machine, a fresh state can send every accepting configuration toward one terminal sink at the right endmarker. The original input accepts exactly when its initial configuration lies in that sink tree. Nonaccepting cycles in other components are harmless. The graph fact uses determinism; an undirected path in a general nondeterministic transition graph does not certify directed reachability.

## Role in the source argument

Supplies a reversible tour for the companion local matching representation of deterministic machines.

## Antecedents and comparison

The source explicitly relates configuration-tree traversal to Sipser's halting method and [Lange-McKenzie-Tapp, Reversible Space Equals Deterministic Space](https://doi.org/10.1006/jcss.1999.1672). Full-text retrieval of that antecedent failed in this audit; its exact correspondence remains source-attributed. The elementary sink and contour proofs were checked directly in the source.

## Checks and limitations

All small partial successor maps with a prescribed sink are checked for basin/component equality and the tree edge count. Tree tours under varied cyclic orders visit every directed edge once. A nondeterministic fork supplies a counterexample to undirected reachability.

The cell-local diagram construction and the claimed automata lower bounds are outside this extraction.

## Possible applications

Reducing deterministic reachability to a reversible traversal without first eliminating cycles elsewhere in the configuration graph.

These are proposed uses; no subsequent application is recorded for this instrument.
