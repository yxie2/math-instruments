# One common generator set pays for all layered rank losses

[Family 111](../families/openai-math-111.md) · [Source manuscript](../papers/P-000111.md) · [Batch B010](../../batches/B010/README.md)

## Mathematical content

Let F0 subset F1 subset ... subset Fm be nested subsets of a finite matroid. For each i suppose F_{i-1} subset A_i subset A_i union S_i subset F_i. Let the enlarged conditioning set B_i lie between A_i and cl(A_i union J), for one common set J. Then

$$\sum_i[\operatorname{rk}(S_i\mid A_i)-\operatorname{rk}(S_i\mid B_i)]\le\operatorname{rk}(J\mid F_0)-\operatorname{rk}(J\mid F_m)\le\operatorname{rk}(J)\le |J|.$$

The individual loss is bounded by rk(S_i|A_i)-rk(S_i|A_i+J), which equals rk(J|A_i)-rk(J|A_i+S_i). Decreasing conditional rank bounds this by rk(J|F_{i-1})-rk(J|F_i). These terms telescope. Missing indices can be inserted because the filtration increments are nonnegative.

In the source, the fixed parity of layer endpoints produces the nested filtration, and a union of guards and later density-path generators supplies J simultaneously for every time. The set J may depend on the entire realized masks: the rank argument is pointwise and requires no independence of J.

## Role in the source argument

Avoids charging the same later generators again at each layer, preserving the competitive accounting budget.

## Antecedents and comparison

This is a direct consequence of matroid rank submodularity and the rank chain identity. Its reusable feature is the explicit requirement of one common generator set, not a new submodularity inequality.

## Checks and limitations

Small binary linear matroids check conditional ranks, each local charge and the summed bound. A changing-generator example shows why replacing J separately at each layer would invalidate a single shared budget.

The nested-set inclusions are essential. A bound on each |J_i| alone does not replace a bound on a common J covering all conditioning enlargements.

## Possible applications

Amortized rank accounting for successive contractions, adaptive filtrations and online independence constraints.

These are proposed uses; no subsequent application is recorded for this instrument.
