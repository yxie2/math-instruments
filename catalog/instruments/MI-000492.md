# Correct a dyadic approximate sampler by a rare exact residual

[Family 115](../families/openai-math-115.md) · [Source manuscript](../papers/P-000271.md) · [Batch B049](../../batches/B049/README.md)

## Mathematical content

Let Omega have M>=1 elements and let an approximate sampler have exactly tabulable dyadic law p_z=a_z/2^R. Choose delta=2^(-D), D>=1, with (1-delta)p_z<=1/M for every z. Then r_z=[1/M-(1-delta)p_z]/delta is a probability law, and (1-delta)p+delta r is exactly uniform.

The residual has integer numerators n_z=2^(R+D)-M(2^D-1)a_z>=0, whose sum is M 2^R. Thus it can be sampled by drawing an integer uniformly in [0,M 2^R) and using cumulative n_z. To draw uniformly from [0,V), use ceil(log2 V) fair bits and reject numbers at least V; acceptance exceeds one half, with V=1 requiring no bits. The delta branch is selected by D fair bits all being zero, followed by fresh sampling bits.

A total-variation error at most delta^2 is sufficient if M delta<=1: each p_z<=1/M+delta^2 and (1-delta)(1/M+delta^2)<=1/M. The expected cost is the branch overhead plus (1-delta)T_approx+delta T_residual. Polynomial expected time therefore requires quantitative control of both costs; exact correction alone does not provide it. The source chooses delta small enough to suppress an explicitly bounded exponential tabulation cost.

## Role in the source argument

Converts the source bounded-time approximate table sampler into exact sampling with an expected-time bound.

## Antecedents and comparison

[Gobel-Liu-Manurangsi-Pappik, arXiv:2410.00882v2](https://arxiv.org/pdf/2410.00882v2), Section 3.1, Algorithm 1 and Theorem 6, already give this residual-mixture mechanism and its expected-cost accounting. Those passages were read. Version 1 uses a different rejection formulation; the reference here intentionally pins version 2.

## Checks and limitations

Exact enumeration of small dyadic laws verifies nonnegative residual integers, their total, and uniform output. Insufficient branch mass gives a negative residual. Integer-rejection acceptance is checked exactly.

No claim that the source approximate sampler or its exponential tabulation bound has been validated. The generic correction needs those as separate inputs.

## Possible applications

Perfect sampling when a very accurate cheap sampler and an expensive exact probability table are both available.

These are proposed uses; no subsequent application is recorded for this instrument.
