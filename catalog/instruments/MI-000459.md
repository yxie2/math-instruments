# Prove graph-alphabet commutation by switching odd path components

[Family 169](../families/openai-math-169.md) · [Source manuscript](../papers/P-000248.md) · [Batch B044](../../batches/B044/README.md)

## Mathematical content

For a natural unit interval graph define the alternating form Omega(b,a)=1 for an edge a<b, and zero for a nonedge. In the quantum torus X_m X_n=v^Omega(m,n) X_(m+n), let E_j be the sum of X_(sum I) over independent j-sets I. Then E_j E_k=E_k E_j.

For an ordered pair of independent sets I,J, their intersection consists of isolated doubled vertices. In the remaining induced graph, the earlier and later neighbors are cliques, so bipartiteness forces components to be increasing alternating paths. Switch membership in I,J on precisely the odd-vertex components. This exchanges the total set sizes, preserves the exponent vector, and preserves the skew weight: an odd path has equally many +1 and -1 edge contributions. The map is an involution.

Commutation permits evaluating symmetric polynomials by e_j -> E_j. It does not prove positivity after expressing monomial symmetric functions in the elementary generators, because those expressions can involve subtraction.

## Role in the source argument

Defines a commuting graph alphabet inside a noncommutative torus for the source coloring kernel.

## Checks and limitations

Exact Laurent coefficients agree in both orders for 11,627 independent-set pairs across all 64 natural unit interval graphs through five vertices.

These checks cover commutation only, not elementary positivity or the later coefficient transport.

## Possible applications

Constructing commutative generating alphabets within skew algebras.
