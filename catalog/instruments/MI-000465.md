# Keep two-variable tree contractions inside an oriented operator algebra

[Family 054](../families/openai-math-054.md) · [Source manuscript](../papers/P-000251.md) · [Batch B046](../../batches/B046/README.md)

## Mathematical content

Suppose all branches off the path joining two distinguished variables reduce to fixed scalar or diagonal inputs. Along the path, let one sector T have nondegenerate symmetric pairing q and vertex tensors q(Au,v), with A in a fixed unital algebra G, written in the path orientation. Let a second sector W have only scalar multiples of its pairing, and require every mixed-sector vertex tensor to vanish.

Contracting q(Au,x) and q(By,v) against the inverse pairing gives q(BAu,v). Thus the T-to-T path stays in G, the W-to-W path remains scalar, and a path that changes sector vanishes. No adjoint closure of G is required: it is the consistent slot order that gives ordinary composition.

In the source, Hodge-difference conservation and diagonal side-branch outputs isolate this path in a genus-zero degeneration tree. Those geometric inputs and the allowed tensor type at every vertex must be established before using the algebraic conclusion. The stated source degrees are even, so no odd-degree permutation signs enter.

## Role in the source argument

Preserves restrictions on bilinear tensors through degeneration and reconstruction.

## Antecedents and comparison

Elementary contraction against an inverse bilinear form. The useful interface records orientation and the required vertex hypotheses.

## Checks and limitations

Sixty exact rational examples with noncommuting A and B verify the BA order.

The checks do not verify virtual classes, Hodge identifications or reconstruction induction.
