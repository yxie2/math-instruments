# Convexify a capacity functional into a norm compatible with coordinate masks

[Family 077](../families/openai-math-077.md) · [Source manuscript](../papers/P-000387.md) · [Batch B064](../../batches/B064/README.md)

## Mathematical content

For a finite complex array c in one time bin, let K(c) be the source quadratic capacity supremum over independently translated frequency and position ellipses. Its normalization gives K(c)>=||c||_infinity². Put G(c)³=w²||c||_2² K(c)^(1/2) and

A(c)=inf {sum_j G(a_j): |c|<=sum_j |a_j| coordinatewise, finitely many atoms}.

Then A is a norm, depends only on absolute values, is monotone and is contracted by coordinate masks. Indeed G(c)>=w^(2/3)||c||_3, so Minkowski gives the same lower bound for A; singleton atoms give finiteness. Concatenation proves the triangle inequality and scaling proves homogeneity. Across bins of length r, the norm mathcal A=(r sum_I A(c_I)³)^(1/3) satisfies mathcal A(c)³>=r w² sum_v|c_v|³.

If a linear map T obeys B(Tb)<=C G(b) for every input on the specified support and B is an output norm, the same bound holds with A(b). For |d|<=sum|a_j|, allocate each coordinate of d among d_j with the phase of d, sum d_j=d and |d_j|<=|a_j|. First restrict atoms to the allowed support, using monotonicity of G. The output triangle inequality gives B(Td)<=C sum G(a_j); take the infimum. An estimate only on analyzed packet coefficients would not suffice for arbitrary atomic pieces.

## Role in the source argument

Allows packet estimates to survive arbitrary coordinate decompositions and masks.

## Antecedents and comparison

This is classical lattice atomic convexification and phase-aligned decomposition. The source capacity supplies the cubic lower bound. The exact full capacity supremum is not replaced by a numerical finite dictionary in the theorem.

## Checks and limitations

Finite mask-closed atom dictionaries test their associated linear-programming norms, triangle and mask inequalities, cubic lower bounds and phase-aligned allocations. These dictionary norms are upper approximations to the full A.

The program does not optimize the full continuum ellipse capacity or prove the packet propagation theorem.

## Possible applications

Replacing a nonconvex homogeneous input cost by a genuine norm without changing uniform linear operator estimates.

These are proposed uses; no subsequent application is recorded for this instrument.
