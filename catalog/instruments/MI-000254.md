# A persistent block event yields a Gaussian-relative entropy deficit

[Family 298](../families/openai-math-298.md) · [Source manuscript](../papers/P-000146.md) · [Batch B018](../../batches/B018/README.md)

## Mathematical content

Write ||D||_(2,d)^2=sum_i tr_d(D_i^2). Fix p and v>0. Let E_d be the event that ||D_[p]||_(2,d)<=4 sqrt(vp) and some p-block projection decomposition P satisfies rank(P_l)<=2d/p and ||sum_l P_l D_[p] P_l||_(2,d)>=sqrt(p)/4. It is a deterministic Borel event: for each rank list the decomposition space is a compact unitary orbit, and the maximized compressed norm is continuous.

For independent variance-v GUE coordinates, a unitary delta-net with delta=1/(64 sqrt(v)) has at most (1+2/delta)^(2d^2) points. Replacing a witness by a net point changes the compressed norm by at most 2delta||D_[p]||, so a net point still has norm at least sqrt(p)/8. For a fixed rank list, the projected squared norm has law (v/d^2)Q, where Q is chi-squared with q=p sum_l r_l^2<=2d^2 degrees. Its moment E exp(Q/4)=2^(q/2) gives

$$\log\gamma_d(E_d)\le p\log(d+1)+d^2\left[2\log(1+128\sqrt v)+\log2-\frac p{256v}\right].$$

If the bracket is below -8, then gamma_d(E_d)<=exp(-4d^2) for all sufficiently large d. Here p is fixed before d tends to infinity.

For a retained ensemble A with a block witness of compressed squared norm >p/2 and the same rank cap, adding independent sqrt(t)G has expected compressed noise energy <=2t. If 32t/p<1/8 and the first p second moments tend to vp after noise, Markov bounds give mu_d(E_d)>=1/2 eventually.

More generally, mu_d(E_d)>=a and gamma_d(E_d)<=exp(-c d^2) imply KL(mu_d||gamma_d)>=ac d^2-log2 by binary data processing. If all n Gaussian reference variances are v_i and E tr_d(Z_i^2)->v_i, the exact Gaussian cross-entropy formula gives

$$\limsup_d H_d(Z)\le\frac12\sum_i\log(2\pi e v_i)-ac.$$

The source uses a=1/2,c=4 and keeps only one unit of the resulting two-unit deficit. Its structural witness and free-probability parameters are separate inputs.

## Role in the source argument

Converts block structure surviving Gaussian noise into a quantitative deficit for exactly the ensemble in the preceding card.

## Antecedents and comparison

Binary relative-entropy data processing, covering by unitary nets and chi-square moment bounds are classical. The source-specific candidate is their combination with a persistent spectral-block witness and a retained matrix law; no standalone novelty claim is made for the component inequalities.

## Checks and limitations

Read the block transfer, event proof and entropy calculation. Finite checks cover block dimensions, normalized covariance, conjugation Lipschitz bounds, chi-square tail estimates, binary data processing and explicit asymptotic parameter margins.

The rare-event estimate is asymptotic in d for fixed p; a large but fixed p is required. The existence of the source limiting tuple and its block witness is not proved by these tests. The entropy bound applies to the stated law, not every model with the same limiting moments.

## Possible applications

Deriving entropy deficits from a structural event that remains common under a model but exponentially rare under its Gaussian reference.

These are proposed uses; no subsequent application is recorded for this instrument.
