# Extract a multivariate coefficient by averaging over nonzero field elements

[Family 141](../families/openai-math-141.md) · [Source manuscript](../papers/P-000170.md) · [Batch B024](../../batches/B024/README.md)

## Mathematical content

Let V(x,t) have total degree at most d, select h of the variables x, and fix a nonnegative multi-index beta. Return zero immediately if any beta_i>d or |beta|>d. For a prime p>d+1 and fixed remaining variables t in F_p,

$$[x^\beta]V(x,t)=(p-1)^{-h}\sum_{z\in(\mathbb F_p^*)^h}V(z,t)z^{-\beta}.$$

For each monomial, the average of z_i^(alpha_i-beta_i) is one if the exponent difference is a multiple of p-1 and zero otherwise. Because both exponents lie between zero and d<p-1, only equality survives. When h=0 there is one empty tuple, so the identity includes the no-extraction case.

The degree cutoff is essential: x^(p-1) aliases the constant coefficient if it is allowed. In the source modular-family bookkeeping, raise the pre-existing prime cutoff to at least d+1; the summation tuple is internal to the evaluation algorithm, not a new index of the integer family. The cutoff must not depend circularly on the prime being queried. Coefficient extraction removes monomials and does not increase degree or coefficient l1 norm.

## Role in the source argument

Keeps coefficient operations inside the source modular evaluation framework without constructing a large explicit polynomial.

## Antecedents and comparison

This is finite-group character orthogonality applied coordinatewise. The extracted bookkeeping clarifies the strict no-aliasing cutoff and the distinction between internal summation variables and external family indices.

## Checks and limitations

96 exact polynomial examples over primes 5, 7 and 11 pass, including h=0. At p=7, allowing x^6 gives the expected false constant coefficient.

The program verifies the algebraic filter, not the claimed counting-hierarchy closure level or real-algebraic reductions.

## Possible applications

Coefficient access from evaluation oracles when field size can exceed the relevant degrees.
