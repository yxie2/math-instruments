# A common degree event transfers single-site tests to adaptive cut norms

[Family 012](../families/openai-math-012.md) · [Source manuscript](../papers/P-000099.md) · [Batch B007](../../batches/B007/README.md)

## Mathematical content

Let $n\asymp B^{0.32}$ independent finite site variables define symmetric zero-diagonal kernels $E_{ij}(S_i,S_j)$ and a nonnegative symmetric envelope H>=|E|. Assume, uniformly in i and every type of S_i,

$$\mathbb E[\sum_jH_{ij}\mid S_i]\le C_0,\qquad \sum_j\mathbb EH_{ij}^2\le C_1B^{-0.21}=:q_B.$$

Assume also that for all fixed single-site functions |g_i|,|h_i|<=1,

$$\left|\frac1n\sum_{i,j}\mathbb E[E_{ij}g_i(S_i)h_j(S_j)]\right|\le E_0+o(1),$$

with the error uniform over the tests. Then the source's sampling proof gives $\mathbb E\|E(S)\|_\square\le E_0+o(1)$, allowing the maximizing signs to depend on every site.

Conditional independence within a row gives a common degree event with maximum envelope degree $d_B=KB^{0.07}$, failure probability $O(B^{-0.03})$, and $\mathbb E(n^{-1}\sum|E_{ij}|)^2\le C_0^2+q_B$. Markov adds the squared-mass event $n^{-1}\sum E_{ij}^2\le B^{-0.20}$ with failure $O(B^{-0.01})$.

For each fixed m-column set and sign assignment, m=floor(n B^-0.18), condition only on those site types. The remaining variables stay independent and the sampled row signs become fixed single-site functions. The residual absolute column sum Z has conditional mean at most $E_0+o(1)+\sqrt{q_B}$. Between any two configurations in the induced degree event, Z is $4d_B/n$-Lipschitz in Hamming distance. This is a bound between arbitrary good configurations, not merely adjacent ones.

Clamp Z at a fixed level and extend from the good set by the infimum Lipschitz formula. Its mean changes by o(1), and bounded differences gives a tail at most $\exp(-a^2n/(8d_B^2))$. The number of column/sign assignments has logarithm $O(B^{0.14}\log B)$, smaller than the concentration exponent of order B^0.18. Union-bound only these exponential tails. The full degree event implies every induced degree event, so its polynomial failure probability is counted once. The bounded second moment of total mass removes the final exceptional event in expectation.

## Role in the source argument

Allows arithmetic labels to depend on the complete divisibility pattern while still using a comparison initially proved only against separate endpoint functions.

## Antecedents and comparison

The source combines established [cut sampling](https://arxiv.org/abs/math/0702004), McShane extension and [bounded differences](https://doi.org/10.1017/CBO9781107359949.008). The specific contribution selected here is its control of an unbounded kernel using integrated second moments and a single shared exceptional event. Targeted searches did not establish historical priority.

## Checks and limitations

Read the conditional-mean, global Hamming-Lipschitz and uniform-integrability arguments. Finite product-space calculations check the conditional variance bound and the clamped extension. The numerical checks do not prove the asymptotic transfer or the arithmetic inputs.

An unconditional mean degree bound cannot replace the every-type conditional bound used here. Conditioning on the optimizing assignment itself would destroy the stated independence. The source proves bounds uniform for each fixed position parameter, without requiring one good event for all positions.

## Possible applications

Transferring separable kernel comparisons to observables that adapt to a whole sampled graph or arithmetic configuration.

These are proposed uses; no subsequent application is recorded for this instrument.
