# Condition random-cluster edges while retaining physical connectivity conventions

[Family 223](../families/openai-math-223.md) · [Source manuscript](../papers/P-000493.md) · [Batch B078](../../batches/B078/README.md)

## Mathematical content

For a finite graph with boundary partition xi, q>0 and odds v_e>0, assign A weight q^(k_xi(A)) product_(e in A) v_e. Conditioning a fixed set of edge bits contracts its open edges and deletes its closed edges; the remaining law has the same q and remaining odds on the induced quotient graph. Loops and parallel edges are retained.

Given all other bits, the opening probability of e is v_e/(1+v_e) if its endpoints are already connected in the boundary quotient, and v_e/(q+v_e) otherwise. Identifying a pair of vertices changes each unnormalized weight by either 1 or q^(-1). Thus finitely many identifications give bounded normalized likelihood ratios for fixed q; if raw ratios lie in [a,b], normalized ratios lie in [a/b,b/a].

A stopped decision-tree leaf is specified only by the inspected bits. The conditioning rule does not permit adding an event involving uninspected edges. Physical paths use actual edges; network paths may jump within wired boundary classes. With just two separately wired terminal sets their connection agrees with an actual path between the sets, but arbitrary additional wiring can create a shortcut with no physical path.

## Role in the source argument

Keeps exact conditional laws and connectivity meanings intact during adaptive explorations.

## Antecedents and comparison

[Grimmett, The Random-Cluster Model, arXiv:math/0205237](https://arxiv.org/abs/math/0205237), Theorem 3.4 on PDF page 12, was read for the classical single-edge and deletion/contraction rules. The source makes the decision-leaf and physical-path qualifications explicit.

## Checks and limitations

Exact rational configuration sums compare conditional and quotient laws with loops, parallel edges, heterogeneous odds and several q values. Adaptive-leaf and hidden-event controls distinguish valid conditioning. An extra wired class demonstrates a nonphysical shortcut.

These finite identities give no positive-association statement for q<1 and no crossing or interface estimate.

## Possible applications

Auditing adaptive random-cluster exploration laws without confusing quotient connectivity with an actual lattice path.

These are proposed uses; no subsequent application is recorded for this instrument.
