# Build exact defining equations from squared-distance separators

[Family 166](../families/openai-math-166.md) · [Source manuscript](../papers/P-000217.md) · [Batch B036](../../batches/B036/README.md)

## Mathematical content

For a finite real point set P, let D be its set of nonzero squared distances and M=1+|D|. For p in P define

$$s_p(X)=\prod_{r\in D}\frac{\sum_j(X_j-p_j)^2-r}{-r}.$$

Then deg s_p=2(M-1) and s_p(q)=1 if q=p, otherwise zero. Consequently the common complex zero set of

$$1-\sum_{p\in P}s_p,\qquad (X_j-p_j)s_p\quad(p\in P,\,1\le j\le n)$$

is exactly P: the first equation forces at least one nonzero s_p, and its coordinate equations force X=p. The degrees are at most 2M-1. The empty-set case uses the equation 1=0. Separators also give the source's Bezout induction bound |P intersect V|<=C_n deg(V) M^{dim V}, by taking proper sections until dimension drops.

## Role in the source argument

Turns few-distance information into explicit algebraic isolation and point-counting bounds.

## Antecedents and comparison

This is classical polynomial separation and Bezout, not a new independent distinct-distance theorem. The useful artifact is the exact common-zero-set construction, including complex points.

## Checks and limitations

Three rational planar point sets have exact Kronecker values, stated degrees and symbolic common zero sets equal to the input points.

The symbolic checks do not validate the source high-dimensional global incidence argument.

## Possible applications

Producing bounded-degree equations for finite configurations from pairwise invariant values.

These are proposed uses; no subsequent application is recorded for this instrument.
