# A chronological paired query exactly represents survival in greedy triangle removal

[Family 188](../families/openai-math-188.md) · [Source manuscript](../papers/P-000123.md) · [Batch B013](../../batches/B013/README.md)

## Mathematical content

Assign distinct priorities to the triangles of a finite simple graph and scan them increasingly, accepting a triangle if all three edges are still present and deleting them. Independent uniform priorities give the same accepted-triangle sequence law as uniform sequential removal: the next present triangle is the first among a uniformly ordered unscanned set.

A singleton query (e,t) asks whether e survives strictly before t. Its candidates are all triangles containing e. A child query has focus {f,g} contained in a parent triangle T and threshold U_T; its candidates are all triangles meeting either focus edge, except T. Each candidate S meets the focus in exactly one edge e(S), because distinct triangles cannot share two graph edges.

Expose the full candidate list, sort by priority, and inspect candidates with U_S<t in that joint order. Query the pair S minus {e(S)} at threshold U_S. At the first child returning true, return false; if none succeeds, return true. All occurrences use the same priority U_S for a triangle type. Every recursive threshold strictly decreases, so every branch has at most the total number of triangles and the finite evaluation terminates.

The answer is exactly joint survival of the focus. Induct on the number of priorities below t. If a focus edge was removed, its accepting triangle is a successful candidate. Conversely, if a successful candidate exists while the whole focus supposedly survives to t, all three candidate edges were present at its priority, a contradiction. Parent omission applies only to the current list at its own threshold; it does not remove that triangle globally from descendant lists.

## Antecedents and comparison

The random-priority representation and backward packing exploration are classical; see [Spencer, Sections 1 and 4](https://cs.nyu.edu/~spencer/papers/asympacking.pdf). The selected item preserves the joint two-edge query, strict thresholds and local parent omission.

## Checks and limitations

Read the finite induction and stopping rule. Exhaustive priority permutations on small graphs compare every tested singleton and parent-pair query with direct chronological deletion, including thresholds equal to triangle priorities.

The two focus-edge survival events need not be independent. The query tree can be much larger than the graph and is an exact representation, not a polynomial-time claim.

## Possible applications

Backward determination of greedy packing decisions when a rejected object depends jointly on several resources.
