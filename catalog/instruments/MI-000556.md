# Repair an idempotent in an exponential weight while preserving every class trace

[Family 207](../families/openai-math-207.md) · [Source manuscript](../papers/P-000325.md) · [Batch B057](../../batches/B057/README.md)

## Mathematical content

For an idempotent e in M_q(l1(G)), choose a finite-support approximation a sufficiently close that b=4(a-a^2) has l1 norm less than one. Set

Q=sum_(j>=0) binom(2j,j)b^j/4^j, and p=I/2+(a-I/2)Q.

The factors commute with a, Q^2(I-b)=I, and (a-I/2)^2=(I-b)/4, so p is idempotent. Let Gamma be generated by the finite support of a, with any finite word metric. The norm ||v||_c=sum_h |v(h)|_1 exp(c|h|) is submultiplicative. Since b has finite support, its weighted norm tends to its unweighted norm as c decreases to zero. Some c>0 therefore has ||b||_c<1, and the same series converges in that weighted algebra. The matrix entrywise l1 norm of I is q, which does not affect convergence of the positive powers.

As a tends to e, p tends to e. The element u=pe+(I-p)(I-e) satisfies ue=pu and u-I=(p-e)(2e-I). For a sufficiently close, the latter has norm below one, so u is invertible and p=ueu^(-1).

For any conjugacy class C, T_C(v)=sum_(h in C) tr v(h) is continuous and tracial: absolute convergence permits swapping the factors indexed by x,y, and xy is conjugate to yx. Hence every class trace is preserved exactly by this repair. Passing from Gamma to G only merges conjugacy classes and preserves element orders. Thus a trace-support statement for these exponentially decaying representatives would imply the corresponding statement for every original l1 idempotent.

## Role in the source argument

Reduces the source all-group l1 theorem to a setting where polynomially weighted sums converge in each fixed dimension.

## Antecedents and comparison

[Blackadar, K-Theory for Operator Algebras](https://www.bruceblackadar.com/Mathematics/book6.pdf), Proposition 4.3.2 on printed page 21 and Proposition 4.5.1 on page 22, prove nearby-idempotent similarity and repair by functional calculus; those complete propositions and proofs were read. The source weighted-norm choice is an explicit implementation of these classical ideas, not a new general perturbation theorem.

## Checks and limitations

Sixteen noncommutative S3 matrix group-algebra examples test the correction series, weighted tail bounds, idempotence, the explicit intertwiner and preservation of all three conjugacy-class traces. Maximum observed residual is below 8e-16.

Finite groups do not test infinite-support convergence. That step relies on the weighted Banach-algebra proof. No Bass trace-support theorem follows from repair alone.

## Possible applications

Obtaining stronger coefficient decay for a representative without losing algebraic trace invariants.

These are proposed uses; no subsequent application is recorded for this instrument.
