# Least separating patterns select a coset covariantly

[Family 244](../families/openai-math-244.md) · [Source manuscript](../papers/P-000157.md) · [Batch B021](../../batches/B021/README.md)

## Mathematical content

Let Gamma=G/K act on the relevant data F. Suppose patterns P_F^alpha(gamma) lie in a fixed wellordered set at each ordinal level alpha, some level separates all cosets, and transport satisfies

$$P_{\sigma F}^\alpha(\sigma\gamma)=P_F^\alpha(\gamma).$$

Take the least separating level, then the unique coset with least pattern there. Left translation permutes the cosets but leaves the actual pattern objects unchanged, so the separating level is unchanged and the selector satisfies c(sigma F)=sigma c(F).

The source constructs patterns from countably many detector sequences modulo eventual equality. Elements of K fix each detector sequence eventually, making the pattern independent of representatives. Distinct cosets eventually move detector indices apart; distinct Cohen rows then have distinguishing bits. Regularity of kappa bounds the countably many bit ordinals, and countability of Gamma gives one level separating every pair. A separate no-new-countable-sequences theorem puts all bounded patterns into a ground set with a fixed ground wellorder. These model-specific hypotheses are retained as inputs here.

To make a preliminary assignment f0 equivariant, its transported value at gamma=pi K must be evaluated using the moved data pi^(-1)F: schematically f^gamma(F)(j)=T_pi^(pi^(-1)F)(f0(pi^(-1)F)(pi^(-1)j)). Residual K-covariance makes this representative independent. Substituting gamma=c(F) then gives full covariance. Simply transporting the computation made at the original F does not satisfy the same identity.

## Role in the source argument

Removes arbitrary componentwise choices while retaining symmetry of the eventual quotient bijection.

## Antecedents and comparison

Selecting the least invariantly transported pattern is a standard group-action argument. The source-specific contribution is the detector system intended to make it available in the symmetric model; those forcing inputs are not certified by this card.

## Checks and limitations

Read the complete selector and transport calculation. Exact S3 models check selection and assignment covariance under every group element, and exhibit failures when the preliminary computation is made at the unmoved data.

Finite regular group actions do not test eventual equality, regular uncountable bounds or the no-new-sequences premise. If patterns fail to separate cosets, choosing a unique least coset by this rule is not justified.

## Possible applications

Turning arbitrary local assignments into symmetry-compatible ones when a common pattern order is available.

These are proposed uses; no subsequent application is recorded for this instrument.
