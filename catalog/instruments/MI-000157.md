# Overlap components give an entropy bound for bad block arrangements

[Family 013](../families/openai-math-013.md) · [Source manuscript](../papers/P-000100.md) · [Batch B007](../../batches/B007/README.md)

## Mathematical content

Fix a partition of rm labeled variables into r labeled blocks of m slots, and compare it with a permutation into a second such set of slots. Join a first block to a second block for each shared variable, retaining parallel edges. Every vertex has degree m. Consequently each connected component contains the same number a_i of blocks on either side, and $\sum_i a_i=r$.

For fixed paired component partitions, at most $\prod_i(a_im)!$ permutations respect them. Let $A_r=\sum_{t=1}^r S(r,t)^2t!$, an upper bound on the number of paired partitions, where S denotes a Stirling number of the second kind. If the overlap graph has more than (1-alpha)r components, 0<=alpha<=1, then $\sum_i(a_i-1)<\alpha r$ and

$$N_{\rm bad}\le A_r(m!)^r\exp\{\alpha rm(\log r+1)\}.$$

Indeed, $(am)!\le(m!)^a a^{am}$ and $a\log a\le(a-1)(\log r+1)$ for 1<=a<=r. Therefore

$$\frac{N_{\rm bad}}{(rm)!}\le A_r\exp\{[-(1-\alpha)\log r+1+\alpha]rm\}.$$

This explicit bound is an abstraction of the source's alpha=1/4 estimate. There r=2^l, l is fixed while the number m of bulk variables per leaf grows, and additional nonbulk arrangements contribute a depth-dependent constant. The complementary pairs are handled by a separate finite-field correlation estimate.

## Role in the source argument

Shows that the arrangements not covered by the source’s low-component correlation estimate have sufficiently small total proportion for symmetrization.

## Antecedents and comparison

The proof uses elementary regular bipartite multigraph counting and multinomial bounds. It is an extracted combinatorial component of the source, not a claimed new counting theorem. The wider [inverse-sieve context](https://arxiv.org/abs/1311.6176v1) is separate from this finite estimate.

## Checks and limitations

Read the full component-count proof. Exhaustive permutations for small block systems verify the component balance, exact bad counts and displayed upper bound; integer partitions test the factorial inequalities.

A_r depends strongly on r. The assertion does not give a useful small fraction for every small r,m, and it is not uniform when tree depth grows with the arithmetic scale. A small exceptional fraction must still be paired with a bound on individual exceptional contributions.

## Possible applications

Symmetrizing block-structured moments or diagram expansions when correlation depends on the number of connected overlap components.

These are proposed uses; no subsequent application is recorded for this instrument.
