# Dense finite oracle transcripts remove auxiliary real parameters

[Family 241](../families/openai-math-241.md) · [Source manuscript](../papers/P-000155.md) · [Batch B021](../../batches/B021/README.md)

## Mathematical content

If Y is not Turing reducible to A, then {(u,v):Y<=_T A join C(u) join C(v)} is meager in R^2, where C(x) is the set of rational numbers below x. The reduction index is allowed to depend on (u,v).

Fix an index e and restrict to irrational coordinates. Suppose its success set were dense in some rational open rectangle R. On input n, search relative to A for a finite halting transcript whose answers about A are correct and whose proposed answers about the two cut oracles hold throughout some nonempty open subrectangle of R.

For each coordinate, a positive answer to q requires q<x and a negative answer requires x<=q. A finite table holds throughout an open interval precisely when its largest lower bound is less than its smallest upper bound, including the rectangle endpoints. This is decidable rational arithmetic; repeated queries must agree.

A successful irrational pair provides an accepting transcript, because no queried rational equals its coordinate. Conversely any accepted transcript is correct: its open subrectangle meets the dense success set, and the same deterministic computation there returns Y(n). The search would compute Y from A, a contradiction.

Thus each fixed-index success set is nowhere dense. Take the countable union over indices and add the countable union of rational-coordinate lines. This proves the claim without selecting one index uniformly on the entire success set.

## Role in the source argument

Turns a generic degree bound involving two auxiliary reals into a bound without those parameters.

## Antecedents and comparison

This is the relative category cone-avoidance principle attributed to Sacks; see [Kumar-Shelah, Large Turing independent sets, Lemma 4.1](https://home.iitk.ac.in/~krashu/ltis.pdf). The source spells out the finite rational-cut transcript test.

## Checks and limitations

Read the full proof. Exhaustive finite two-coordinate cut tables check the strict interval-feasibility rule and reject inconsistent repeated queries.

A finite transcript enumeration does not establish the Baire-category theorem or decide arbitrary Turing reducibility. Irrational coordinates are used to turn an actual finite computation into an open neighborhood.

## Possible applications

Eliminating generic auxiliary oracles from a nonuniform family of computability bounds.

These are proposed uses; no subsequent application is recorded for this instrument.
