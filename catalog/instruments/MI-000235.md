# Row-sparse near-isometries have a uniform programmable-slot encoder

[Family 283](../families/openai-math-283.md) · [Source manuscript](../papers/P-000137.md) · [Batch B016](../../batches/B016/README.md)

## Mathematical content

Let T:C^d -> C^U have at most L nonzero entries per row, d<=2^n, rows encoded by w qubits, and (1-epsilon)I<=T*T<=I with 0<=epsilon<1. A programmable slot is an arbitrary table-controlled one-qubit unitary; the whole table counts as one slot. In this model, a unitary U_T with w+h+2 fresh qubits, h=ceil(log2(L+1)), satisfies ||U_T iota-jmath T||<=5 epsilon using O(L(n+w+h)) slots. The structure depends only on dimensions and L and works coherently for label-indexed families.

Set theta=pi/(4L+2), t0=sin(theta). Controlled on input i, prepare its column in a row register and success flag, with remaining norm in a failure flag. For each row u, pad its support to exactly L distinct extended input indices I_u. Inverting the preparation of the uniform state on I_u gives overlap 1/sqrt(L) on every supported input. A second flag of amplitude t0 sqrt(L) yields a unitary B with jmath*B iota=t0 T.

After B apply L rounds of (2B P0 B*-I)(I-2Q), where P0=iota iota* and Q=jmath jmath*. On each right singular direction with singular value sigma, the state lies in a two-dimensional plane with angle beta=arcsin(t0 sigma); the final angle is (2L+1)beta. Its distance from sigma times the desired left singular vector is at most (pi+1)(1-sigma)<=5 epsilon. Different singular directions have orthogonal planes, so the same bound holds in operator norm, including coherent labels.

Arbitrary column-state tables and support lists are available in this input model. This is not an efficient algorithm given only entry queries or a classical dense matrix.

## Role in the source argument

Implements the near-isometric Fourier fields while controlling all input superpositions and retained workspace.

## Antecedents and comparison

State-preparation block encodings and singular-value amplification are established; compare [Gilyen-Su-Low-Wiebe, Lemmas 47-48 and the amplification results](https://arxiv.org/pdf/1806.01838v1). The source uses a different arbitrary-table slot model and an explicit 5 epsilon estimate; the sparse-access oracle costs of that antecedent cannot be substituted directly.

## Checks and limitations

Read the preparation block and orthogonal-plane proof. Finite sparse rectangular contractions test a unitary dilation with the specified block, L amplification rounds and the full operator-norm error, including exact isometries.

The numerical dilation tests the singular-value argument, not the entire table-controlled circuit compilation. Slot count must not be presented as a standard finite-gate count.

## Possible applications

Coherent implementation of row-sparse near-isometries when arbitrary controlled state-preparation tables are supplied.

These are proposed uses; no subsequent application is recorded for this instrument.
