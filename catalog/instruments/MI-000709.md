# Regroup weighted directed edges into nonnegative level-cut fluxes

[Family 149](../families/openai-math-149.md) · [Source manuscript](../papers/P-000478.md) · [Batch B075](../../batches/B075/README.md)

## Mathematical content

Let a finite directed graph have a return path for every edge, positive rates k_e and positive vertex weights w_v. Assign real levels a(v), and suppose a(u)<a(z) implies w_z<=delta w_u for every pair of vertices. If delta sum_e k_e<min_e k_e for a nonempty edge set, then sum_e k_e w_(source e)[a(target e)-a(source e)]>=0.

List distinct levels alpha_1<...<alpha_q and let Q_j be upward minus downward weighted flux across the cut at alpha_j. If a downward edge exists, its return path contains an upward edge e0 with lower source u. The all-pairs hypothesis bounds the entire downward flux by delta w_u sum_e k_e<k_e0 w_u, so Q_j>0. If no downward edge exists, Q_j>=0 directly.

Each edge level difference is the signed sum of the consecutive gaps it crosses. Hence the original sum equals sum_j (alpha_(j+1)-alpha_j) Q_j. Repeated levels, disconnected components and an empty edge set are allowed. The chosen upward edge need not share a component with every downward edge, which is precisely why ordering only adjacent pairs would not justify this proof. For mass action, use a(y)=r dot y and w_y=x^y once the required monomial ordering has been established.

## Role in the source argument

Isolates the finite graph reason for inward motion of an active affine label.

## Antecedents and comparison

[Craciun, arXiv:1901.02544v1](https://arxiv.org/abs/1901.02544v1), Theorem 4.1, proof on pages 18-21, orders complexes and regroups cycle contributions across level gaps. That portion, including the single-cycle argument away from uncertainty regions, was read. The source gives a direct all-pairs domination estimate for general return-path graphs; exact priority of that finite formulation is not established.

## Checks and limitations

Exact rational models test cut decompositions on cycles and disconnected weakly reversible graphs with tied levels. Removing return paths or weight separation produces negative flux controls.

The tests do not supply the source global monomial ordering or a persistence theorem.

## Possible applications

Separating reaction-network geometry from a reusable finite weighted-graph inequality.
