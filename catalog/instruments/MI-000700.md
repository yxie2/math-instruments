# Compile deterministic episode updates from universally sound splits

[Family 134](../families/openai-math-134.md) · [Source manuscript](../papers/P-000469.md) · [Batch B074](../../batches/B074/README.md)

## Mathematical content

Let E be a prefix code, D' subset D subset E, and let each episode e have a total deterministic state update G_e on finite S. Suppose P_x,Q_y are universally sound: whenever uv is a prefix of w in D* with u in P_x and v in Q_y, uv is exactly the first episode e and G_e(x)=y. Require a successful split for each e in D minus D' and each input state.

Write W_(x,y) for exact graph tests on (D')*. Then the graph test on D* is
D* intersect [W_(x,y) union (union_a W_(x,a)P_a)(union_(b,c) Q_b W_(b,c)P_c)* (union_r Q_r W_(r,y))].
Membership in D* fixes the true episode parsing. Each adjacent P,Q pair starts at an actual boundary, so universal soundness advances the deterministic computation by one episode; W consumes skipped episodes. Conversely split every non-skipped episode. The empty word is handled by W. If D,P,Q have heights at most 1,0,1 and W has height H, the displayed expression has height at most max(2,H+1).

Affine updates v->vA_e+b_e may be used without losing the desired product of linear parts: the composite has linear part g_w(v)-g_w(0). On a finite vector space, the graph test for output y is union_z [R_(v,y+z) intersect R_(0,z)], using the same word in both tests. Boolean operations do not increase star height; invertibility is unnecessary.

## Antecedents and comparison

Prefix-code parsing, expression concatenation and recovery of an affine map from its value at zero are established ideas. The selected source emphasizes universal soundness of independently accepted split witnesses; that condition must be proved by later constructions.

## Checks and limitations

A concrete prefix code and deterministic updates compare the expression against direct parsing on every short binary word. An omitted-domain negative control detects spurious words. Exact affine composites check recovery with singular linear maps.

The tests do not establish the source marker rules, universal end guard or uniform height bound.
