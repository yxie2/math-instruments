# Normalized containment maximizers give small cores with conditionally spread extensions

[Family 176](../families/openai-math-176.md) · [Source manuscript](../papers/P-000132.md) · [Batch B015](../../batches/B015/README.md)

## Mathematical content

Let H have an edge and at most n vertices, and let q be its graphic expectation threshold defined by expected unlabelled copies of every subgraph being at least 1/2. Remove isolated vertices from edge subsets but retain this original q. For a graph F on its incident vertices let M(F)=(n)_(v(F))/|Aut(F)|, and let M(I,F) count copies inside I. A uniform copy Ibold on [n] contains any fixed copy F0 with probability M(I,F)/M(F).

Set sigma=128q. For a nonempty I subset H choose S subset I, allowing the empty set, that maximizes sigma^(-|S|)Pr(S0 subset Ibold). If r=|S|>0 then the first-moment constraint gives the upper bound 2 binom(|I|,r)128^(-r). For r>=|I|/17 this is below one, whereas the empty set gives one. Hence every maximizer has |S|<|I|/17.

Conditional on a fixed copy S0 being contained in Ibold, the added edge set A=Ibold minus S0 is sigma-spread. For J disjoint from S0, its conditional inclusion probability is Pr(S0 union J subset Ibold)/Pr(S0 subset Ibold), and maximality bounds this by sigma^|J|. For J meeting S0 it is zero.

Iterate cores to the empty set and reverse the sequence H0,...,Hk. Uniform extensions of each reached copy form a probability tree, keeping distinct histories as distinct nodes. Path labels are disjoint, their union is a copy of H, and their sizes ell_i=|H_i|-|H_(i-1)| satisfy ell_(i+1)>16 ell_i and ell_k<=e(H).

## Role in the source argument

Organizes graph containment into a logarithmic hierarchy of individually spread extensions with separated capacities.

## Antecedents and comparison

This core-maximization and conditional-extension method is explicitly credited to [Tran, Section 3 and Lemma 3.1](https://arxiv.org/pdf/2609.20546v2). The release changes constants and interfaces it with its tree-covering argument. It is not a new core-selection principle.

## Checks and limitations

Read copy normalization, core-size estimate and conditional ratio. Small graph copy enumerations check the symmetry identity. Arbitrary finite set laws check normalized-maximizer conditioning, including nonempty maximizers; elementary arithmetic checks the stated size threshold.

Copy counts are not raw embedding counts; automorphisms matter. Removing isolates does not redefine q. The hierarchy alone does not establish the claimed product-sample covering bound.

## Possible applications

Building conditionally spread blocks from first-moment constraints before applying a separate covering or sampling theorem.

These are proposed uses; no subsequent application is recorded for this instrument.
