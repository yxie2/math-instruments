# Transfer path events using unused departure rows

[Family 220](../families/openai-math-220.md) · [Source manuscript](../papers/P-000491.md) · [Batch B078](../../batches/B078/README.md)

## Mathematical content

For a finite nearest-neighbor word gamma=(x_0,...,x_m), let Dep(gamma)={x_0,...,x_(m-1)} and let W(gamma)=E product_(j<m) omega(x_j,x_(j+1)-x_j). If f is nonnegative and measurable with respect to rows outside Dep(gamma), iid rows give
E[f product_(j<m) omega(x_j,x_(j+1)-x_j)]=E[f] W(gamma).

Repeated departures from the same site remain inside the same row expectation; they are not independent draws of that row. The terminal row is unused unless the path departed from it earlier. Thus two quenched-independent paths with disjoint departure sets have the same annealed joint word probability under a shared environment as under independent environments.

Stopping at the first arrival in a target set has not queried the arrival row. Countable finite-prefix decompositions and a monotone-class argument extend the transfer to stopped-trajectory events, including never hitting. One must first transfer the unclassified path event; inserting an exit-probability classification depending on both used and unused rows can invalidate the factorization.

## Role in the source argument

States exactly which environment information is independent of an observed path.

## Antecedents and comparison

This is the product-measure regeneration mechanism. The source makes departure sets and the order of subsequent classification explicit; no new independence principle is claimed.

## Checks and limitations

Exact finite mixtures of row types compare shared and independent environments for disjoint departure sets, repeated visits and a terminal-row overlap. Treating repeat departures as fresh rows supplies a failing control.

Finite word checks do not validate an infinite regeneration construction or a directional zero-one law.

## Possible applications

Auditing hidden conditioning in random-environment explorations.

These are proposed uses; no subsequent application is recorded for this instrument.
