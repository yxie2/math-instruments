# Homogenize every lookup block, including the constant table

[Family 137](../families/openai-math-137.md) · [Source manuscript](../papers/P-000168.md) · [Batch B024](../../batches/B024/README.md)

## Mathematical content

For a Boolean word u of length d and augmented field vector z=(z_1,...,z_d,z_*), set

$$B_u(z)=\prod_{i:u_i=1}z_i\prod_{i:u_i=0}(z_*-z_i).$$

At (v,1) this is the indicator of v=u. A total Boolean lookup f on a fixed number a of words has the extension

$$\widetilde f(z^{(1)},...,z^{(a)})=\sum_{u^{(1)},...,u^{(a)}}f(u^{(1)},...,u^{(a)})\prod_{j=1}^a B_{u^{(j)}}(z^{(j)}).$$

It agrees with the lookup on augmented Boolean inputs and is homogeneous of degree d in each block. This includes the zero polynomial. The constant-one table extends to prod_j (z_*^(j))^d, which matters at zero augmentation; replacing it by the field constant one would destroy homogeneity.

When the field-valued input blocks are already supplied, enumerate Boolean words, evaluate their Boolean table entry and accumulate basis products. The extra memory holds a fixed number of word counters, field scalars and the Boolean evaluator workspace. This coordinate evaluator does not recursively request its input words. The paper uses finite fields of polynomial cardinality in T and O(log T)-bit representations; uniform construction and arithmetic bounds are separate ingredients.

## Role in the source argument

Allows the recursive evaluator to recover a desired homogeneous term even after arbitrary translations.

## Antecedents and comparison

This is the usual Boolean multilinear basis with one homogenizing coordinate per input block. The source-specific requirement is to keep the same homogeneous extension for every table, including constants and values away from Boolean inputs.

## Checks and limitations

Over F_16, 94 Boolean agreements, 300 block-homogeneity identities and 300 zero-augmentation controls pass for several word lengths and arities.

The finite program does not implement the space-bounded recursive word evaluator, uniform field tower or Turing-machine simulation.

## Possible applications

Algebraic encodings of finite lookups that must remain homogeneous on non-Boolean and zero-augmentation inputs.

These are proposed uses; no subsequent application is recorded for this instrument.
