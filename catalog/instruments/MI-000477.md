# Use a bounded death horizon to turn local persistence into global injectivity

[Family 345](../families/openai-math-345.md) · [Source manuscript](../papers/P-000257.md) · [Batch B047](../../batches/B047/README.md)

## Mathematical content

For a filtered homology system V_a -> V_b -> V_infinity, suppose every class in ker(V_a -> V_infinity) maps to zero by a+D, where D is uniform. If the transition V_a -> V_(a_+) is injective for some a_+>a+D, then V_a -> V_infinity is injective: a globally dying class is zero at a+D, hence at a_+, so injectivity kills it already at a. Over a field, the corresponding ordinary cohomology restriction is surjective.

The source obtains short-window injectivity away from moving degree bands. For finitely many event types, assume event times m ell_i, centers I_(i,m) satisfying |I_(i,m)-m Delta_i|<=n, and local contributions confined to |j-I_(i,m)|<=C_loc, with the neighboring exact-sequence degrees included in this bound. Put beta_i=Delta_i/ell_i and choose a_+ in (a+D,a+D+1). Any intervening event that can affect j satisfies

|j-beta_i a|<=C_loc+n+beta_i(D+1).

Outside all these fixed-width bands, the crossing sequences give the required injectivity. Combining it with bounded death excludes hidden globally dying classes in those degrees. The later equivariant gap isomorphisms need further Gysin and global nilpotence inputs and are not asserted by this extraction.

## Antecedents and comparison

Elementary persistence-map factorization and a triangle inequality for the event bands. The value is the explicit uniform interface, not a new general persistence theorem.

## Checks and limitations

Finite barcode models check that global death and the horizon condition force loss before the tested later cut; delayed-death controls violate the horizon. Event-time models check the fixed-width band formula.

The uniform death horizon and local crossing support are substantive geometric inputs, left unverified here. The finite models do not establish the full degree-gap lemma or transient bound.

## Possible applications

Proving stability away from moving spectral or index bands when short-lived classes have a uniform lifetime bound.

These are proposed uses; no subsequent application is recorded for this instrument.
