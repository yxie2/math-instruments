# Control stationary fluctuations relative to each dyadic block chord

[Family 152](../families/openai-math-152.md) · [Source manuscript](../papers/P-000285.md) · [Batch B051](../../batches/B051/README.md)

## Mathematical content

For a real stationary process with E Y_0^2<infinity, put A_h=2^(-h) sum_(t<2^h)Y_t and Z_h=2^(-h) max_(0<=u<=2^h)|sum_(t<u)Y_t-u A_h|. Define v_l=E A_(l-1)^2-E A_l^2. Adjacent half-block averages U,V and W=(U+V)/2 satisfy v_l=E(U-W)^2>=0, using stationarity but no independence. Telescoping gives sum v_l<=E Y_0^2.

Interpolate the cumulative-sum polygon at dyadic meshes. Refining a mesh with 2^a intervals inserts midpoint displacements 2^(h-a-1)(U_j-W_j). A squared maximum is bounded by the sum of squares, so the normalized L2 size of this refinement is at most 2^(-a/2-1) sqrt(v_(h-a)). Summing refinements yields ||Z_h||_2<=one-half sum_(a=0)^(h-1)2^(-a/2)sqrt(v_(h-a)).

The convolution kernel has l1 norm 1/[2(1-2^(-1/2))]. Consequently sum_(h>=1)||Z_h||_2^2<= [4(1-2^(-1/2))^2]^(-1) E Y_0^2. The same bound holds at any deterministic starting time. The chord slope is the realized block average A_h, not E Y_0; replacing it by the mean is false in this generality, for example for a nonconstant stationary process that is constant along each sample path.

## Role in the source argument

Provides square-summable orbit-segment errors for stationary derivative logs without assuming an ergodic convergence rate.

## Antecedents and comparison

A targeted search found general stationary maximal inequalities based on dyadic induction, but did not settle an exact antecedent for this chord-centered bound. Its full elementary source proof was checked. The interpolation and convolution steps are classical; no novelty certificate is attached to the formulation.

## Checks and limitations

Exact randomly shifted periodic processes verify variance losses and finite sums of squared chord deviations. Numerical evaluation checks the square-root convolution bound. A stationary random constant process is a control against replacing the block chord by the process mean.

This estimate alone does not supply a uniform spatial derivative splitting, a smooth switch or the claimed obstruction to realization.

## Possible applications

Finding long stationary orbit segments with controlled deviations from their own linear trends when no quantitative mixing rate is available.

These are proposed uses; no subsequent application is recorded for this instrument.
