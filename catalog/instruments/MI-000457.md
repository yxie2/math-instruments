# Recover replica consensus and mean residual after clipping

[Family 136](../families/openai-math-136.md) · [Source manuscript](../papers/P-000247.md) · [Batch B044](../../batches/B044/README.md)

## Mathematical content

Let J be orthogonal averaging onto vectors constant across each replica group. Assume AJ=J and ||A(I-J)X||<=(1-kappa)||(I-J)X|| with 0<kappa<=1. Let c be constant on each group and use the same coordinate clipping interval within a group. For F=clip(AX+c), E=||X-F||, and g=clip(JX+c), one has

$$\|X-JX\|\le E/\kappa,\qquad \|JX-g\|\le E/\kappa.$$

Indeed g is in ran J and clipping is nonexpansive, so ||(I-J)F||<=||F-g||<=(1-kappa)||(I-J)X||. Project X-F to get the first inequality. Taking means gives ||JX-g||<=E+||JF-g||<=E+(1-kappa)||(I-J)X||. The base norm is identified with the norm of a repeated vector.

This never asserts J clip(Y)=clip(JY), an identity which is generally false.

## Role in the source argument

Turns small clipped fixed-point residual into synchronized replicas and a small base displacement.

The source bounded-degree replica construction and global circuit soundness are separate inputs.
