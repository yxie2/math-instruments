# Rule out generalized invariant functions by descending their differentials

[Family 060](../families/openai-math-060.md) · [Source manuscript](../papers/P-000252.md) · [Batch B046](../../batches/B046/README.md)

## Mathematical content

Let Y -> X be a connected infinite cyclic cover of a compact connected complex manifold with H^0(X,Omega^1)=0, and let T generate the deck group. If a holomorphic f on Y obeys f composed T-f=c for a constant c, then df is deck invariant and descends to a holomorphic one-form on X. Hence df=0, f is constant and c=0.

Writing Delta=T*-1, every holomorphic f killed by Delta^m is therefore constant. If the least exponent were m>1, Delta^(m-1)f would descend to a nonzero constant on X. Then Delta^(m-2)f would have a nonzero constant difference, which the first argument excludes. If m=1, f descends and is constant by compactness.

The algebraic mechanism is kernel stabilization: ker Delta consists of constants and im Delta intersects the constants trivially, so no longer Jordan chain can end there. Without the geometric hypotheses, the conclusion can fail; translations of the coordinate function on C give a constant difference.

Excludes generalized trivial-character holomorphic modes in the source cover analysis.
