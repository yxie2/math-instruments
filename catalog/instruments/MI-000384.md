# Implement a rational matrix shear with one interchange per rank

[Family 109](../families/openai-math-109.md) · [Source manuscript](../papers/P-000211.md) · [Batch B035](../../batches/B035/README.md)

## Mathematical content

Every rational m-by-m matrix A of rank a has A=E_1 Pi E_2, with E_1,E_2 invertible lower triangular and Pi a partial permutation matrix with a ones. Choose the topmost active nonzero row and its rightmost nonzero entry. Lower-triangular column operations clear its left entries; lower-triangular row operations clear below. Repeating on the remaining ordered indices gives LAR=Pi.

For a fixed finite matrix family, choose an odd prime q avoiding all factor denominators and nonzero diagonal numerators. The identities specialize over Z/q^b Z for every b. For ordered field groups H before D, transform D by E_2 and H by E_1^{-1}. Each one Pi_ij requires H_i+=D_j, implemented using only later-field arithmetic and one swap:

$$D_j\leftarrow D_j+H_i,\quad(H_i,D_j)\leftarrow(D_j,H_i),\quad D_j\leftarrow H_i-D_j.$$

Undo the triangular transformations. The result is (H+AD,D), with exactly rank_Q(A) interchanges. The source's linear extra-work claim assumes its ordered-affine stream operations and fixed m; the finite algebra alone does not establish that tape cost.

## Role in the source argument

Turns a finite rank budget into a bound on expensive recursive address interchanges.

## Antecedents and comparison

The factorization is classical Bruhat elimination, explicitly credited by the source. The useful interface is the one-swap realization of each partial-permutation entry.

## Checks and limitations

Sixty exact rational eliminations and modular shear realizations, including singular matrices, perform 158 rank-counted swaps.

No tape implementation or interchange recurrence was executed; the source complexity claim is outside this check.

## Possible applications

Separating inexpensive triangular updates from expensive field exchanges in ordered data layouts.

These are proposed uses; no subsequent application is recorded for this instrument.
