# Turn divergent field decisions into polynomial factors

[Family 142](../families/openai-math-142.md) · [Source manuscript](../papers/P-000234.md) · [Batch B040](../../batches/B040/README.md)

## Mathematical content

Let F in F_p[T] be monic, square-free and split, with unknown roots x_i in F_p, and let k/F_p be explicitly represented. Then A=k[T]/F is a product of copies of k. A deterministic scalar procedure using arithmetic, zero tests and integer control can run simultaneously on all components until it either completes with common decisions or produces a proper factor of F.

For a zero test of a in A, compute d=gcd(F,a) over k. If d=1, every component is nonzero and extended Euclidean inversion is valid; if d=F, every component is zero. Otherwise d separates the components. Its monic coefficients lie in F_p because its roots are a subset of the original prime-field roots. Degree and pivot choices reduce to coefficient zero tests. Each simulated instruction has polynomial overhead in deg F, [k:F_p] and log p.

This is a per-instruction overhead statement. It does not by itself bound how many instructions the scalar procedure needs.

## Role in the source argument

Lets source algorithms work with unknown roots without assuming a completed factorization; a failed common branch is already useful output.

## Antecedents and comparison

The source attributes this to D5 dynamic evaluation. [Duval s own research bibliography](https://membres-ljk.imag.fr/Dominique.Duval/Research/evdyn.html) identifies its 1985 introduction by Della Dora, Dicrescenzo and Duval. This is a classical method, not a new extraction discovery.

## Checks and limitations

One hundred exact polynomial gcd models across four prime fields check component zero sets and unit inversion; 48 yield proper splits.

The tests use prime-field components only. No deterministic full-factorization runtime is established.

## Possible applications

Executing algebraic algorithms over unknown components and using divergent pivots as splitting certificates.

These are proposed uses; no subsequent application is recorded for this instrument.
