# Protected-cell sampling and opposite bit propagation separate copy hitting from repair

[Family 190](../families/openai-math-190.md) · [Source manuscript](../papers/P-000125.md) · [Batch B013](../../batches/B013/README.md)

## Mathematical content

Use a height-h binary tree with m=2^h. At depth i<h each node has separate plus and minus row and column blocks of size m/2^i; at depth h the two signs share one leaf position. Rows occur in minus-subtrees-plus order; columns use plus-subtrees-minus order. Dummy blocks supply ones. Six modes per level, pinned by the preceding anchor, compare consecutive row levels or consecutive column levels, with child parity specified for the latter.

Avoiding P=((1,0),(1,1)) enforces b<=a in ((1,a),(1,b)) and a<=b in ((a,b),(1,1)). The source sets the two root diagonal values to one and zero. Its order and role choices propagate these opposite values to the same leaf cell if all selected mode bodies avoid P.

For robustness, partition each axis into size-m classes: each anchor group, dummy group, each signed nonleaf level and the single shared leaf level. Choose a uniform leaf z on both axes and independently choose positions within its ancestor blocks, with one choice for the shared leaf. Each variable choice is marginally uniform on its class. Anchor and dummy choices are independent of choices on the opposite axis; root choices are also independent. Thus every cell touching an anchor or dummy, and every root-root cell, is selected with probability exactly 1/m^2.

For any fewer than m^2 arbitrary edits, a union bound gives a selection with all these protected cells unchanged. Other variable cells may be edited freely. The unchanged anchors enforce the body rules, unchanged dummy incidences enforce both propagation inequalities, and unchanged opposite root bits then contradict the shared leaf. Hence the matrix is at least m^2 edits from H-free. Its order is n=(386h+2)m, giving normalized distance at least (386h+2)^(-2).

In the original matrix every copy has its fixed body top-left entry on one of m diagonal leaf cells; therefore its normalized copy count is at most 2^(-h)/(386h+2)^2. Flipping those m ones destroys every original copy but creates a plus-mode body P using an unchanged parent-child one and the new leaf zero. Original-copy hitting is therefore not an H-free repair. The protected-cell argument handles both directions of editing without assuming independence of all sampled variable cells.

## Role in the source argument

Produces polynomially large edit distance together with exponentially few copies as the tree height grows.

## Antecedents and comparison

[Alon and Ben-Eliezer](https://arxiv.org/pdf/1609.04235v3) formulate the ordered binary problem and discuss ternary obstructions. The selected binary mechanism combines protected-cell sampling, mode pinning and conflicting values at identified leaves; prior ternary constructions are not treated as proving it.

## Checks and limitations

Read all four mode checks, the leaf copy count and arbitrary-edit argument. Finite models verify the tree orders, every small mode body, creation of new copies after leaf flips, and impossibility of satisfying all protected propagation constraints.

The full matrix distance lower bound follows from the proof, not exhaustive edit search. Correlations between variable selections matter: the 1/m^2 probability is asserted only for the listed protected cells.

## Possible applications

Constructing induced-property testing obstructions where edits that hit old witnesses can create new witnesses.

These are proposed uses; no subsequent application is recorded for this instrument.
