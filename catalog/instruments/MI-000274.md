# A shifted inverse identity gives one natural-number code for each rational

[Family 242](../families/openai-math-242.md) · [Source manuscript](../papers/P-000156.md) · [Batch B021](../../batches/B021/README.md)

## Mathematical content

Represent a rational by natural numbers (p,n,d,t,s,q) satisfying

$$pn=0,\qquad d=1+t+s,\qquad(p+n)t+d=1+qd.$$

Its value is (p-n)/d. The equations imply d>0, 0<=t<d and gcd(p+n,d)=1. Thus the signed numerator and positive denominator are reduced and uniquely determined by the rational. If d>1, t is the unique inverse of p+n modulo d in [0,d-1]; then s=d-1-t and q=((p+n)t+d-1)/d are uniquely determined nonnegative integers. If d=1, t=s=q=0. Zero consequently has code (0,0,1,0,0,0).

A prescribed rational arithmetic operation on valid codes has a polynomial implementation by clearing positive denominators and imposing the same code conditions on its output. For example a1/d1+a2/d2=a3/d3 becomes a1 d2 d3+a2 d1 d3=a3 d1 d2. Nonzero divisor guards are required for division, and comparisons use positive denominator products and unique natural slacks. Once the rational output is specified, its entire code is unique.

## Role in the source argument

Prevents arbitrary Bezout witnesses or denominator choices from multiplying the solutions of elliptic-curve arithmetic encodings.

## Antecedents and comparison

Normalized coprimality witnesses are established in [Cantone-Cuzziol-Omodeo, Section 2](https://lematematiche.dmi.unict.it/index.php/lematematiche/article/download/2703/1218/7841). The source shifted identity incorporates denominator one in the same formula; no general novelty claim is made for rational encoding.

## Checks and limitations

Read the full proof. Exhaustive bounded enumeration finds 511 distinct valid codes with no duplicate rational values, including all denominator-one and zero cases. Exact rational arithmetic checks additional output codes.

Bounded enumeration is not a uniqueness proof over all natural numbers; that conclusion follows from reduced fractions and the normalized inverse argument. Elliptic rank and growth inputs are separate.

Canonical algebraic-number data structures when the number of auxiliary solutions matters.
